# MazeRunner

Unity로 만든 3D 미로 탈출 게임입니다.

## GitHub Pages로 웹 배포하기

1. Unity에서 `File > Build Profiles`를 열고 `Web` 프로필을 추가한 뒤 전환합니다.
2. `Build`를 눌러 이 프로젝트의 `docs` 폴더를 출력 위치로 선택합니다.
3. 생성된 `docs/index.html` 파일을 확인합니다.
4. 변경 사항을 GitHub에 올린 뒤, GitHub 저장소의 `Settings > Pages`에서 `Deploy from a branch`를 선택합니다.
5. 브랜치는 `main`, 폴더는 `/docs`로 설정하고 저장합니다.

배포 주소는 `https://GitHub아이디.github.io/저장소이름/` 형식입니다.
